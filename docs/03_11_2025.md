## The art of writing efficient programs

### Chapter 3: CPU Architecture, Resources, and Performance
CPU's have a lot of tools to optimize usage of compute resources, most of which is left idle

Instruction level parallelism: As long as operands are already in the registers the processor can execute several operations at once
Machine code analyzer: Part of the llvm toolchain. Takes assembly code as input and reports a lot of information on how the instructions are executed

Pipelining: When a complex expression is broken into stages and executed in an interleaved fashion. Stage 2 of previous expression can run at same time as stage 1 of current expression.

Register Renaming: The registers we see in the MCA are not the actual register names but mappings to them

Loop Unrolling: converting a loop to linear code

Conditional Move & Conditional Add: Special instructions that the compiler can use on certain processors to enhance the ability to pipeline executions.

Branch Prediction: Analyze the history of every branch and assume that the behavior will not change. 

Speculative Execution: Used in branch prediction to execute code before the processor knows it exists

Pipeline Flush: Happens when speculative execution fails, expensive operation.

The perf profiler can help a programmer profile for branch mis-predictions 

Branchless Computing: Rewriting a program to use no or far fewer branches. This often involves doing more operations, but given the cost of branching logic a program could come out ahead. The goal here is to conditionally access data instead of conditionally execute code
